# مغامرة مستكشفي البيانات

لعبة تعليمية تفاعلية ثلاثية الأبعاد باللغة العربية لوحدة **تمثيل البيانات** في رياضيات **الصف الثاني الابتدائي**، بهوية سعودية سينمائية: واحة نخيل، وحصن نجدي من الطين بشرفاته المثلثة، وسجادة سدو، ودلة قهوة وفناجين، ودليل المغامرة **شاهين** (صقر بوشاح أخضر).

- **لعب فردي**: كل طالبة تدخل باسمها ورمز فصلها، وتلعب مراحل المغامرة بنفسها.
- **مؤثرات صوتية** تُولَّد داخل المتصفح (بلا ملفات صوتية ولا حقوق نشر): نغمات تفاعل، ونسيم صحراوي، ولحن هادئ على مقام الحجاز، وقراءة السؤال بصوت عربي إن توفر في الجهاز.
- **لوحة المعلمة**: تعرض إجابات كل طالبة ونتائجها **لحظيًا** (Cloud Firestore Realtime).
- **مجاني بالكامل**: يعمل على خطة Firebase المجانية **Spark** دون بطاقة بنكية.

## التشغيل السريع (الوضع التجريبي المحلي)

يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

- اللعبة: `http://localhost:5173/`
- لوحة المعلمة: `http://localhost:5173/teacher.html`

دون إعدادات Firebase تعمل المنصة في **الوضع التجريبي المحلي**: البيانات تُحفظ في المتصفح نفسه فقط، ورمز الفصل التجريبي هو `NAJD26`. افتحي اللعبة في تبويب ولوحة المعلمة في تبويب آخر، وستظهر الإجابات في اللوحة فور حدوثها.

## الربط مع Firebase والنشر

اتبعي [دليل إعداد Firebase (الخطة المجانية Spark)](docs/FIREBASE_SETUP.md) خطوة بخطوة. باختصار:

1. أنشئي مشروع Firebase وتطبيق ويب، وفعّلي **Anonymous** و**Email/Password** في Authentication، وأنشئي قاعدة **Cloud Firestore**.
2. انسخي `.env.example` إلى `.env` والصقي إعدادات تطبيق الويب.
3. أضيفي حساب المعلمة في Authentication، ثم أضيفي مستندًا باسم معرّفها (UID) في مجموعة `teachers`.
4. `npm run deploy` لنشر اللعبة وقواعد الأمان على Firebase Hosting.

## الأمان وحماية البيانات

القواعد في [`firestore.rules`](firestore.rules)، ومختبرة آليًا على محاكي Firestore الحقيقي ([`tests/rules`](tests/rules/firestore.rules.test.js)):

- **الطالبة** تدخل بحساب مجهول (Anonymous)، فلا يُطلب منها بريد ولا كلمة مرور، ولا تُخزَّن عنها إلا الاسم الذي تكتبه.
- الطالبة **لا تستطيع قراءة** بيانات أو إجابات أي طالبة أخرى، ولا حتى إجاباتها بعد إرسالها.
- كل إجابة **تُكتب مرة واحدة** ولا يمكن تعديلها أو حذفها من جهاز الطالبة.
- جهاز الطالبة **لا يرسل درجة**؛ يرسل محاولاتها الخام فقط، وتُحسب الدرجة في لوحة المعلمة من مفتاح الإجابة. وأي حقل إضافي (مثل `score`) أو وقت مزوّر ترفضه القواعد.
- **لوحة المعلمة** محمية بالبريد وكلمة المرور، ويجب أن يكون الحساب مضافًا يدويًا في قائمة `teachers` من Firebase Console، فلا يستطيع أحد منح نفسه صفة معلمة.
- المعلمة ترى **فصولها فقط**، ويمكنها إغلاق الفصل لمنع أي كتابة جديدة.

## الأوامر

| الأمر | الوظيفة |
|-------|---------|
| `npm run dev` | تشغيل بيئة التطوير |
| `npm run build` | بناء نسخة النشر في `dist/` |
| `npm test` | اختبارات حساب الدرجات وسلامة ملفات الأسئلة |
| `npm run test:rules` | اختبار قواعد الأمان على محاكي Firestore (يتطلب Java 11+) |
| `npm run deploy` | البناء ثم النشر على Firebase Hosting مع قواعد Firestore |

## بنية المشروع

```
index.html, teacher.html      صفحتا اللعبة ولوحة المعلمة
firestore.rules               قواعد الأمان
src/content/                  المراحل والأسئلة (ملفات JSON قابلة للتعديل)
src/game/                     محرك اللعبة ثلاثي الأبعاد (three.js)
  world.js                    الواحة والحصن النجدي والنخيل والإضاءة
  models.js                   الأشياء والسلال
  activities/                 أنواع الأنشطة: فرز، لمس، اختيار من متعدد
  audio.js                    المؤثرات والأجواء الصوتية
src/backend/                  طبقة البيانات: محلي أو Firebase بالواجهة نفسها
src/shared/scoring.js         حساب الدرجات (يستخدمه جانب المعلمة)
src/teacher/                  لوحة المعلمة
tests/                        اختبارات الوحدات وقواعد الأمان
docs/                         أدلة الإعداد وتعديل المحتوى
```

---

**English summary:** A 3D Arabic (RTL) educational game for Grade 2 "Data Representation", built with three.js + Vite, with a live teacher dashboard on Cloud Firestore (Spark/free plan only). Runs in a local demo mode without Firebase config. Security rules are append-only for student answers, scores are computed teacher-side, and are covered by emulator tests.
