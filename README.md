# مغامرة مستكشفي البيانات

لعبة تعليمية تفاعلية ثلاثية الأبعاد باللغة العربية لوحدة **تمثيل البيانات** في رياضيات **الصف الثاني الابتدائي**، بهوية سعودية نجدية سينمائية.
ترافق الطالبةَ **نورة**: طفلة سعودية بثوب أخضر مطرّز بالذهب وبُخنُق تقليدي، تشرح وتشجّع وتنطق كل التعليمات بالعربية.

- **لعب فردي**: كل طالبة تدخل باسمها وتلعب على جهازها.
- **مصمّمة لحصة Teams مدتها ٤٠ دقيقة** لفصل من ٢١ طالبة (راجعي [دليل الحصة](docs/TEAMS_LESSON.md)).
- **لوحة المعلمة**: نتائج كل طالبة لحظيًا، وتقدّمها في المراحل الخمس، ومحاولاتها، والمهارات التي تحتاج فيها إلى دعم، وتصدير إلى Excel.
- **مجانية بالكامل**: تعمل على خطة Firebase المجانية **Spark** دون بطاقة بنكية.

## المراحل (٣٠ سؤالًا)

| # | المرحلة | المكان | الأنشطة |
|---|---------|--------|---------|
| ١ | الفرز والتصنيف | واحة النخيل | فرز بالسحب أو اللمس (لون، شكل، فئة، ٣ سلال)، تمييز المختلف، قاعدة الفرز |
| ٢ | جداول الإشارات | سوق القرية | قراءة الإشارات والحزمة، عدّ الأشياء ورسم إشاراتها، المقارنة في الجدول |
| ٣ | التمثيل بالصور | قلعة الحصن | قراءة التمثيل والمقارنة، إنشاء تمثيل بالصور من جدول |
| ٤ | الأعمدة البيانية | برج المراقبة | قراءة الأعمدة (مكعبات وحدات تُعدّ)، الأطول والأقصر، إنشاء أعمدة من جدول |
| ٥ | قراءة البيانات والاستنتاج | خيمة الحكماء | كم يزيد؟ المجموع، التساوي، الاستنتاج |

النصوص مشكولة بالكامل وقصيرة (١٠ كلمات على الأكثر)، ولكل جملة ملف صوتي، وتُكتب الأرقام بالأرقام العربية.
بعد ٣ محاولات خاطئة تعرض نورة الإجابة الصحيحة، ويُسجَّل ذلك للمعلمة.

## الصوت

- **صوت نورة:** ملفات MP3 مولَّدة مسبقًا لكل الجمل (`public/voice`)، فلا يعتمد على وجود قارئ عربي في الجهاز. إذا تعذّر تحميل ملف تُستخدم القراءة الآلية في الجهاز.
- **الموسيقى والمؤثرات:** لحن عود هادئ على مقام الحجاز، ونسيم صحراوي، وأصوات للصح والخطأ والاحتفال. كلها تتولد داخل المتصفح.
- **التحكم:** زر «الصوت» يكتم كل شيء أو يشغّله، وزر «الموسيقى» يوقف الموسيقى وحدها، وزر «اختبري الصوت» في شاشة الدخول.
- **سياسة المتصفحات:** المتصفحات تمنع الصوت قبل أول تفاعل، لذلك يبدأ الصوت تلقائيًا مع أول لمسة أو نقرة.

## التشغيل السريع (وضع تجريبي محلي)

```bash
npm install
npm run dev
```

اللعبة على `http://localhost:5173/` ولوحة المعلمة على `/teacher.html`. دون إعدادات Firebase تُحفظ البيانات في المتصفح نفسه، ورمز الفصل التجريبي `NAJD26`.

## النشر مع Firebase

اتبعي [دليل إعداد Firebase (Spark)](docs/FIREBASE_SETUP.md)، ثم:

```bash
npm run deploy
```

## الأمان

القواعد في [`firestore.rules`](firestore.rules)، ومختبرة آليًا على محاكي Firestore الرسمي:

- الطالبة تدخل بحساب مجهول، ولا تقرأ بيانات أو نتائج أي طالبة أخرى، ولا حتى إجاباتها بعد إرسالها.
- الإجابة تُكتب مرة واحدة ولا تُعدَّل. جهاز الطالبة لا يرسل درجة، والدرجة تُحسب في لوحة المعلمة.
- إن وضعت المعلمة قائمة أسماء فلا تنضم إلا طالبة اسمها فيها.
- اللوحة لحسابات المعلمات المسجّلة يدويًا فقط، وكل معلمة ترى فصولها وحدها.

## الأوامر

| الأمر | الوظيفة |
|-------|---------|
| `npm run dev` | بيئة التطوير |
| `npm run build` | نسخة النشر في `dist/` |
| `npm test` | اختبارات المحتوى (صحة الحسابات) والدرجات وتحليلات اللوحة |
| `npm run test:rules` | اختبار قواعد الأمان على محاكي Firestore (يتطلب Java) |
| `npm run deploy` | البناء والنشر على Firebase Hosting مع القواعد |
