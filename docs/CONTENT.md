# تعديل الأسئلة وإضافتها

أسئلة كل مرحلة في ملف JSON داخل `src/content/`، ولا يلزم تعديل كود اللعبة لتغييرها.
المرحلة الأولى: [`src/content/stage1.json`](../src/content/stage1.json).

> **الأسئلة الحالية مسودة** (`"status": "draft"`) وُضعت لاختبار آلية اللعب فقط. بعد مراجعة صفحات الكتاب تُستبدل، ثم تُغيَّر الحالة إلى `"approved"` فتختفي شارة «أسئلة تجريبية».

## بنية الملف

```json
{
  "version": "s1-v1",
  "status": "draft",
  "intro": "جملة شاهين الافتتاحية",
  "questions": [ ... ]
}
```

- `version`: غيّريه عند كل تعديل جوهري للأسئلة، فيُحفظ مع كل إجابة لمعرفة النسخة التي أجابت عليها الطالبة.
- `id` لكل سؤال: فريد وثابت، مثل `s1-q1`. **لا تغيّري معرّف سؤال له إجابات مسجلة**؛ أضيفي سؤالًا بمعرّف جديد بدلًا من ذلك.

## أنواع الأسئلة المتاحة الآن

### ١. الفرز `sort`: تسحب الطالبة كل شيء إلى سلته

```json
{
  "id": "s1-q1",
  "type": "sort",
  "prompt": "ضعي كل كرة في السلة التي لها اللون نفسه.",
  "bins": [
    { "id": "red", "label": "أحمر", "color": "red" },
    { "id": "yellow", "label": "أصفر", "color": "yellow" }
  ],
  "items": [
    { "id": "a", "model": "ball", "color": "red", "bin": "red" },
    { "id": "b", "model": "ball", "color": "yellow", "bin": "yellow" }
  ]
}
```

- من سلتين إلى ثلاث سلال، ومن ٣ إلى ٨ أشياء.
- يمكن إضافة أيقونة أمام السلة تساعد من لا تجيد القراءة بعد: `"icon": { "model": "cube", "color": "blue" }`.

### ٢. اللمس `pick`: تلمس الطالبة الشيء المطلوب

```json
{
  "id": "s1-q4",
  "type": "pick",
  "prompt": "أيُّ شيء لا ينتمي إلى المجموعة؟ المسيه.",
  "items": [
    { "id": "a", "model": "date" },
    { "id": "c", "model": "star", "color": "yellow" }
  ],
  "answer": "c"
}
```

### ٣. الاختيار من متعدد `choice`: مجموعات في المشهد وأزرار إجابة

```json
{
  "id": "s1-q5",
  "type": "choice",
  "prompt": "كيف صُنّفت هذه الأشياء؟",
  "groups": [[ { "id": "a", "model": "cube", "color": "blue" } ], [ { "id": "d", "model": "ball", "color": "orange" } ]],
  "options": [
    { "id": "color", "label": "حسب اللون" },
    { "id": "shape", "label": "حسب الشكل" }
  ],
  "answer": "color"
}
```

## الأشياء والألوان المتاحة

| `model` | الشيء | | `color` | اللون |
|---------|-------|-|---------|-------|
| `ball` | كرة | | `red` | أحمر |
| `cube` | مكعب | | `yellow` | أصفر |
| `cone` | مخروط | | `blue` | أزرق |
| `star` | نجمة | | `green` | أخضر |
| `date` | تمرة | | `orange` | برتقالي |
| `orange` | برتقالة | | `purple` | بنفسجي |
| `apple` | تفاحة | | `brown` | بني |
| `cup` | فنجان قهوة | | `white` | أبيض |
| `dallah` | دلة | | | |

الحجم اختياري: `"size": "small"` أو `"big"`.

## حساب الدرجة

في [`src/shared/scoring.js`](../src/shared/scoring.js):

- **الفرز**: نسبة الأشياء التي وُضعت في سلتها الصحيحة **من أول مرة**.
- **اللمس والاختيار**: ١ للإجابة الصحيحة من أول محاولة، و٠٫٥ من المحاولة الثانية، و٠ بعد ذلك.
- بعد ٣ محاولات خاطئة يرشد شاهين الطالبة للإجابة الصحيحة، ويُسجَّل أنها «عُرضت عليها الإجابة».
- إذا أعادت الطالبة المرحلة، تُعتمد **أول إجابة** لكل سؤال، وتظهر الإعادات في اللوحة دون أن تغيّر الدرجة.

## بعد التعديل

```bash
npm test     # يتحقق أن كل شيء له سلة موجودة، وأن مفتاح الإجابة ضمن الخيارات، وأن المعرّفات فريدة
npm run dev  # جرّبي الأسئلة في المتصفح
```
